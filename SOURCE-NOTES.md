# Sources and snapshot scope

This is the reviewed project snapshot for the public portfolio. The report and datasets retain their definitions, observation dates and limitations. No live market or blockchain connection is needed for the supplied reproduction script.

The database is read-only input. Run `python scripts/reproduce.py` from this repository to rebuild key metrics from its source records or recreate views in memory. The script prints validation results and does not write to the database.

The local reproduction starts from the included structured snapshot, not a fresh external extraction. Full historical request/response evidence remains in the original research archive. Source request tables in the snapshot retain original URLs and relative historical evidence paths; not all historical files are in this curated repository.

Do not interpret historical estimates as current observations. No blanket license is assigned to third-party datasets or reports; retain original attribution.
